
# E-PARKIR XII IND

## Deskripsi Proyek
E-PARKIR XII IND adalah aplikasi sistem informasi parkir berbasis web untuk mempermudah pengelolaan kendaraan dan transaksi parkir.

## Tujuan
Membantu proses pengelolaan parkir agar lebih efektif, efisien, dan terkomputerisasi.

## Teknologi
- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Fitur Admin
- Dashboard Admin
- Manajemen User
- Manajemen Tarif
- Manajemen Area Parkir
- Manajemen Kendaraan
- Log Aktivitas

## Fitur Petugas
- Dashboard Petugas
- Parkir Masuk
- Parkir Keluar
- Cetak Struk

## Fitur Owner
- Dashboard Owner
- Rekapitulasi Parkir
- Laporan Transaksi
